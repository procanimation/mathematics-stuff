# Trigonometry Functions & Fourier Wave Synthesis

Visualizing how harmonic trigonometric circles (epicycles) sum to construct arbitrary waveforms using Fourier's theorem.

## The Mathematical Series

$$\text{Square}(t) = \frac{4}{\pi} \sum_{n=1, 3, 5, \dots}^{N} \frac{\sin(n \omega t)}{n}$$

As $N \to \infty$, the harmonic sum converges to an ideal square wave.
